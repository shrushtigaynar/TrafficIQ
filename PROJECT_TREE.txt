DEVELOPMENT WORKFLOW
════════════════════════════════════════════════════════════════════════════════

To add a new feature:

1. BACKEND LOGIC
   → backend/core/your_module.py

2. API ENDPOINT
   → backend/api/routes.py (create if needed)
   → Register route in backend/main.py

3. FRONTEND UI
   → frontend/src/your_component.js
   → frontend/src/your_component.css
   → Update frontend/public/app.js

4. TESTS
   → backend/tests/test_your_feature.py

5. DOCUMENTATION
   → docs/your_guide.md
   → Update README.md
